# Background Images

This directory contains background images extracted from Figma.

## Required Files

1. **login_background.png** (611x611 px)
   - Node ID: 136:505
   - Purpose: Background image for Login screens

2. **background_pattern_1.png** (512x958 px)
   - Node ID: 229:2538, 364:3329, etc.
   - Purpose: Background pattern/texture for multiple screens

3. **background_pattern_2.png** (364x431 px)
   - Node ID: 349:3354, 353:3195
   - Purpose: Background pattern for profile view screens

4. **background_large.png** (717x1600 px)
   - Node ID: 534:8514
   - Purpose: Large background image (hidden element)
   - Note: May not be needed for initial implementation

## Export Instructions

Export these images from Figma using:
- Format: PNG (for transparency) or JPEG (for photos)
- Scale: @1x, @2x, @3x for different screen densities
- Quality: High quality for production use

## Status

⚠️ **PLACEHOLDER**: These images need to be manually exported from Figma.
The Figma MCP server does not support direct image export.
